Bias–variance

Var(X)=E[D2](expectation of deviation squared, D=X−E[X])=E[(X−E[X])2]=E[X2−2XE[X]+(E[X])2]=E[X2]−2E[X]E[X]+(E[X])2=E[X2]−(E[X])2

Similarly:

Var(X+Y)=E[(X+Y−E(X+Y))2]=E[(aX−μx​​​+bY−μy​​​)2]=E[a2+b2+2ab]=Var(X)+Var(Y)+covariance2E(Dx​Dy​)​​ Cov(X,Y)=E[(X−E(X))(Y−E(Y))]=E[XY−XE(Y)−YE(X)+E(Y)E(X)]=E(XY)−E(X)E(Y)

Since we express r=σx​σy​Cov(X,Y)​: for covariance = 0, X & Y are uncorrelated (since r(X,Y)=0) (but that doesn’t make them independent) or X & Y are independent.

  • ↳ Model bias: average difference between our predicted value and the true value: E[Y^(x)]−g(x)
  • ↳ Model risk: mean squared error of prediction: E[(Y−Y^(x))2]
  • ↳ Model variance: average of predictions across all possible samples: E[(Y^(x)−E(Y^(x)))2] → has got nothing to do with the true model value (just variations in our own predictions)

Bias–variance decomposition:

Model risk=σ2observation variance​​+(model bias)2+model variance

PCA

The goal of PCA is to identify the most meaningful basis to re-express a data set ↳ our hope is that these new bases will filter out the noise and reveal hidden structure, i.e. re-expressing the data as a linear combination of its basis vectors.

Assumptions: (1) linearity; (2) large variances have important structure (PCs corresponding to large variances represent interesting structure); (3) principal components are orthogonal.

A 2D overview of PCA: transforms an N×d matrix (X) into an N×m matrix (Y) (if d = m, then there is no loss of information). Steps:

  1. Centralize data (subtract mean)
  2. Calculate the d×d covariance matrix (diagonals are variances while off-diagonals are covariances b/w i & j)
  3. Calculate the eigenvectors of the covariance matrix (orthonormal)
  4. Select m eigenvectors w/ largest eigenvalues

(sketches: a correlated point cloud in x–y; after finding the covariance matrix & using that to get eigenvalues/eigenvectors, v1​ and v2​ are orthonormal vectors that capture the data variance; plotting on the new axes, the data spread mainly along v2​.)

These eigenvectors obtained are called principal components ↓ we see that v2​ captures the majority of the data while v1​ captures some of it. Therefore, using only v2​ we can get back projected data, Y=XV (sketch: points collapsed onto a line). Using only PC1 we lose variance in the other direction but retain the majority of the structure of the data.

Linear regression

SLR: slope =rσx​σy​​; intercept =μx​−slope⋅μy​.

Transcriber’s note: the SLR intercept is μy​−slope⋅μx​; the subscripts are swapped on the sheet.

Linear regression [w/ changing X, Y parameters], Y^=Xθ^:

  • → Shifting x and y: SD of x and y stay the same (mean changes); parameters don’t change (apart from the intercept); MSE same; r same.
  • → Shifting only x or only y: no change in SD (means change); MSE same; intercept changes.
  • → Scaled both x and y: everything changes (points move closer or further away to the regression line).
  • → Scaling only x: intercept stays the same; MSE same.
  • → Scaling only y: everything changes; if scaled by ½ → MSE will drop (since predicted values are closer to [the sentence is unfinished on the page]).
