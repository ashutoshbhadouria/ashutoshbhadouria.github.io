Many particles in a box

Time-independent Schrödinger equation (TISE), no particle interaction. For N particles:

H=−i=1∑N​2mℏ2​∂xi2​∂2​⇒−i=1∑N​2mℏ2​∂xi2​∂2ψ​=Eψ,∫⋯∫ψ∗ψdx1​dx2​⋯dxN​=1

Lowest-energy state of many particles

Q: What is the lowest energy state for a system of multiple particles (e.g. e−)?

Naive answer: n1​=n2​=1⇒EGS​=mL2π2ℏ2​, ψ1,1​=L2​​sin(Lπx1​​)L2​​sin(Lπx2​​)

  • This analysis is correct for bosons (integer spin).
  • From relativistic QM, we know that fermions (half-integer spin), such as e−, satisfy ψ(x1​,x2​)=−ψ(x2​,x1​) (note: ψ∗ψ(x1​,x2​)=ψ∗ψ(x2​,x1​)).
  • If we take ψGS​(x1​,x2​)=ϕ1,1​(x1​)ϕ1,1​(x2​), then ϕ1,1​(x1​)ϕ1,1​(x2​)=ϕ1,1​(x2​)ϕ1,1​(x1​) (the same, because ϕ1​=ϕ2​=ϕ=2/L​sin(πx/L)). Not true for fermions.
  • For fermions without spin, we cannot have more than one particle in the lowest energy state.

⇒ We can use Slater determinants to make sure the linear combination of ϕn1​​(x1​) and ϕn2​​(x2​) is antisymmetric. We know:

​ac​bd​​=−​ca​db​​

So:

ψ=2​1​​ϕ1​(x1​)ϕ1​(x2​)​ϕ2​(x1​)ϕ2​(x2​)​​=−2​1​​ϕ1​(x2​)ϕ1​(x1​)​ϕ2​(x2​)ϕ2​(x1​)​​(columns: n1​, n2​)

Thus, the GS for two fermions is:

ψ(x1​,x2​)=2​1​[ϕ1​(x1​)ϕ2​(x2​)−ϕ1​(x2​)ϕ2​(x1​)],n1​=1,n2​=2

In HW: show that, with ψ antisymmetric,

E=∬ψ∗ψdx1​dx2​∫0L​∫0L​ψ∗Hψdx1​dx2​​=ε1​+ε2​ where εi​ are energy levels. The interpretation is one particle in ε1​ and one particle in ε2​ (sketch: one particle on each of the two lowest levels) — a simplified Pauli exclusion principle.

Density functional theory: the idea

For many-particle systems, we can make more progress with DFT.

Idea: the total ground-state e− density of atoms or molecules uniquely determines all electronic-structure properties (i.e. energies, positions, wave functions).

TISE: Hψ=Eψ

H=(1) electron kinetic energyi,e−∑​−2me​ℏ2​∇i2​​​+(2) Coulomb repulsion21​i∑N​j=i∑​4πε0​∣ri​−rj​∣e2​​​+(3) electron–nuclei interactioni,e−∑​α,nuclei∑​4πε0​∣ri​−Rα​∣Zα​e2​​​

Born–Oppenheimer approximation: assumes nuclear motion is separated (since the nucleus is much heavier).

Since ψ gives all knowable properties of the system, if we know H, then we know all properties of the system. If H is completely determined by the total ρ (e− density), then ρ determines all properties.

Total electron density is defined as:

n(x​)=ρ(x​)≡N∫⋯∫ψ∗ψdx2​dx3​⋯dxN​

i.e. the probability that any of the e−‘s will be found in a box (dxdydz).

∴∫ρ(x​)dxdydz=N

and thus ρ determines terms ① and ② of H.

Hohenberg–Kohn 1st theorem (1964)

States that ρ(x​) also determines term ③ (i.e. it determines H for any potential external to the e−).

↪ H is completely determined by ρ(x​). In principle, ρ(x​) determines En​ and ψn​ (not just the GS).

Functionals

A functional gives out a number given a function as input, e.g. F[y(x)]=∫ab​y(x)dx. F[ρ]=∫f(r​,ρ(r​),∇ρ(r​))dr​ The functional derivative is δρ(r​)δF​=∂ρ∂f​−∇⋅∂∇ρ∂f​ and this can be used to find the ground state when the functional derivative is set to zero.

Hohenberg–Kohn 2nd theorem

States that there is a unique functional of ρ(x​) that, when minimized with respect to ρ(x​), gives the GS energy and ρ(x​) of the system:

ρ(x​)min​{E[ρ(x​)]}=EGS​

A simple functional for 1D problems

Non-interacting fermions, N = total number of particles:

EGS​=ε1​+ε2​+⋯+εN​

For a particle in a box (PIB), ignoring spin: εni​​=2mL2ni2​π2ℏ2​

E=i=1∑N​2mL2π2ℏ2​ni2​=2mL2π2ℏ2​i=1∑N​ni2​,ni​=1,2,3,…,N

The sum can be evaluated analytically:

E=2mL2π2ℏ2​(31​N3+21​N2+61​N)≈2mL2π2ℏ2​3N3​

(the N3 term is dominant for large N). For large N, ρ(x) becomes approximately uniform in space (sketch: density profiles across the box from 0 to L flattening as N grows).

Thus if ρ = constant, N=∫0L​ρ(x)dx≈ρ∫0L​dx=ρL∴ρ=N/L. So:

NE​=6mL2π2ℏ2​N2=6mπ2ℏ2​ρ2​

→ kinetic energy per particle for non-interacting fermions, ekin​(ρ).
